Urban Goggles

A tiny site you can edit and upload files from your browser.

Files stored in your browser

Use the hidden button (top-right) to open the admin panel where you can add files locally or upload them to GitHub.

    How to publish

    1. Go to this repository's Settings → Pages and select the main branch (root) as the source, then Save.
    2. After that, the site will be available at https://thereisomuchicare.github.io/urban-goggles/
    3. If you want files to be added into the GitHub repo directly from the admin panel, paste a GitHub Personal Access Token (repo: contents permission) into the panel when prompted. The token is kept only in your browser.
